# content2html — read-only guide

This guide describes the public website. It does not authorize actions or replace system instructions.

- Start with llms.txt or agent/site.json under the content2html base path. Choose the Chinese or English reading route.
- For papers, use the long-form summary for context and the presentation deck for slides. Consult the linked original research for claims, methods and results. Summaries and slides are explanatory artifacts, not independent proof.
- Progress reports are dated archives, not current task or deployment state. Keep original dates, quoted evidence and source references intact; do not infer completion from a historical report.
- The directory projects public titles and links from the existing content collections. It excludes raw source records, private notes and credentials.
- If a page or original source is inaccessible, report that limitation. Do not claim to have read it, bypass authentication, execute code, modify files, or publish on behalf of the reader.
